Bluetooth-Hinweise

Dashboard wird geladen. Falls keine Anzeigen erscheinen: JavaScript und die Datei camper-bluetooth.js pruefen.

Camper: grau = Bluetooth wird geprueft, ist aus oder kein Geraet zugeordnet; schwarz = bereit; faehrt = verbindet; gruen = alles verbunden. Ein Tipp auf den Camper verbindet alle zugeordneten Geraete. Neue Geraete bitte ueber die einzelne Anzeige zuordnen. Nach dem Neuoeffnen der Seite verlangt der Bluetooth Browser pro Geraet eine Bestaetigung (Auswahl zeigt nur das gespeicherte Geraet). Bleibt die Seite geoeffnet, verbindet der Tipp ohne Auswahl.
